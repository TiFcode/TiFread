# TiFread

Un timer vizual minimalist pentru ritmul de citit. Ecranul se umple de sus în jos pe durata aleasă și reîncepe automat la finalul fiecărui interval.

## Funcții

- Interval implicit de 60 de secunde, reglabil între 15 și 300 de secunde
- Pauză, reluare și reset din meniul hamburger
- Bip opțional la 1/4, 1/2 sau 1/1 din interval
- Culori și pattern-uri distincte pentru fundal și umplere
- Preferințe salvate local în browser

Aplicația este statică: deschide `index.html` sau servește directorul prin orice web server.
